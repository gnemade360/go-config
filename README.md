# go-config

A flexible and extensible configuration management library for Go applications.

## Features

- Multiple configuration providers (YAML, JSON, TOML, Environment, etc.)
- Hot-reloading capabilities
- Type-safe configuration with struct tags
- Hierarchical configuration with overrides
- Built-in validation
- Extensible provider system

## Installation

```bash
go get github.com/ganeshravi/go-config
```
